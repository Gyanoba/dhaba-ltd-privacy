# Dhaba Ltd privacy policy

The privacy policy for the Android game **Dhaba Ltd** (`com.gyanoba.games.dhaba`) by Gyanoba, published with GitHub
Pages at https://gyanoba.github.io/dhaba-ltd-privacy/. That URL goes into Play Console → App content → Privacy policy.

The page is `index.html`, plain HTML with no build step. When the game starts collecting something new (accounts,
cloud saves, purchases, another SDK), update the page and its date before that version ships, and the Play Console
Data safety form with it.
